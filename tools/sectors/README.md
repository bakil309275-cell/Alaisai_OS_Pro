# محرك إضافات القطاعات

مصدر بناء خمس إضافات (طب، سفر، زراعة، عقارات، منقولات) من محرك واحد. **لا يدخل في تشغيل التطبيق**، وهو أداة بناء فقط.

- البناء: `python3 tools/sectors/build.py` ← ينتج في `tools/sectors/out/` لكل قطاع: مجلد الإضافة وملف `.alaisai-addon.json` للاستيراد.
- التعديل: المنطق المشترك في `engine/js/*`، والتصميم في `engine/style.css`، وإعداد كل قطاع (الحقول والألوان والمصطلحات) في `build.py`.
- الاختبار: شغّل خادماً على المنفذ 8765 ثم `python3 tools/sectors/test.py med 1100`.
- المجلد `out/` يُولَّد ولا يُرفع.
