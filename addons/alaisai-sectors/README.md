# إضافات قطاعات العيسائي برو

نواة مشتركة (`core/`) + إضافة لكل قطاع (`addons/<القطاع>/`). الإضافة الأولى: **الطب والأدوية**.

## التركيب
1. انسخ مجلد `addons/medical/` كما هو إلى `addons/medical/` في مستودع Alaisai_OS_Pro (يحوي أصلاً core.js و core.css).
2. أعد بناء المتجر: `node tools/build-catalog.mjs` ثم انشر.
3. افتح الإضافة من التطبيق.

> **افتراضان يلزم التحقق منهما** لأن ملفات المشروع الأصلي لم تكن متاحة لي:
> - شكل `manifest.json` (الحقول: id, name, version, description, entry, lang, dir, permissions). إن اختلف عن مخطط التطبيق فعدّل الملف فقط.
> - توقيع جسر `Alaisai.get/set` (أفترض أن `get(key)` يعيد القيمة أو نصاً JSON، وأن `set(key, string)` يحفظ نصاً). النواة تتعامل مع الحالتين.

## ما تم
- حقول ديناميكية: أكثر من هاتف/بريد/حساب بنكي/واتساب/فيسبوك… لكل جهة.
- حسابات فورية: المتفق عليه / المدفوع / المتبقي، وقيمة المخزون، وإجماليات اللوحة.
- بحث شامل عبر الجهات والأدوية والحجوزات والمنشورات، يتسامح مع الهمزات والتشكيل والتاء المربوطة والأرقام العربية.
- أزرار كل بطاقة: عرض 👁، تعديل ✏️، حذف 🗑، وقائمة ⋮ (نسخ، طباعة، مشاركة، نشر عام/خاص، إظهار/إخفاء).
- شعار دائري وصورة ترحيبية تظهر أول مرة فقط.
- رفع صورة سند الحوالة/الإيداع مع الحجز.

## غير موجود عمداً (يحتاج خادماً — المرحلة 2)
مراسلة بين المستخدمين، «المتصلون الآن»، «الأعضاء الأكثر نشاطاً»، إيقاف/تحذير الحسابات، إشعارات مركزية، ذكاء اصطناعي.

## إضافة قطاع جديد
1. أنشئ `addons/<اسم>/` بـ manifest.json وindex.html (انسخ من medical).
2. في main.js عرّف مجموعات `AlCore.collection({...})` بحقول القطاع فقط.
3. `node tools/sync-core.mjs` ينسخ النواة إلى كل الإضافات.

## الاختبار
```
node tests/core.test.mjs          # منطق النواة
python3 -I tests/e2e_medical.py   # متصفح حقيقي بحجم هاتف (يحتاج playwright)
```
